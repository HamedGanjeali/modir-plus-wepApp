# مدیر پلاس (Modir Plus — modir-plus.ir)

پلتفرم جامع معرفی، مستندسازی، آموزش و نصب ابزارهای هوشمند ویژه مدیران و معاونین مدارس ایران.

---

## ۱. معرفی مجموعه محصولات

**مدیر پلاس** برند چتری محصولات اتوماسیون اداری و آموزشی مدارس است که کارهای زمان‌بر و تکراری سامانه‌های آموزش و پرورش را به جریان‌های سریع و امن تبدیل می‌کند:

1. **سیدا پلاس (Sida Plus — نسخه ۲.۵.۰):**
   افزونه هوشمند مرورگر برای سرعت‌بخشی به عملیات روزمره سامانه سیدا (`sida.medu.ir`)، چیدمان هوشمند برنامه هفتگی، صفحه‌بندی رسمی دفتر آمار و امتحانات، مدیریت تصاویر دانش‌آموزان و عضویت گروهی/مدیریت لینک‌های شاد (`web.shad.ir`).
   - فعال‌سازی و اشتراک در ربات بله: `@sidayar_license_bot`

2. **کارنامه پلاس (Karnameh Plus — نسخه ۱.۰.۰):**
   سامانه یکپارچه مدیریت نمرات، حضورغیاب و انضباط ۶ زنگی، پورتال وب اختصاصی دبیران/معاونین/اولیا (`karnameh.medu-plus.workers.dev`) و موتور چاپ کارنامه‌های رسمی (A4/A5/A6) ویژه دوره متوسطه اول.
   - فعال‌سازی و اشتراک در ربات بله: `@Karnameh_plus_bot`

---

## ۲. پشته فنی (Tech Stack)

- **فریم‌ورک:** Astro + React Islands (`TypeScript`)
- **استایل‌دهی:** Tailwind CSS v4 + CSS Logical Properties (`RTL`) + فونت `Vazirmatn`
- **هاستینگ:** Cloudflare Pages / Static Edge (`modir-plus.ir`)
- **سیاست اشتراک:** معرفی شفاف با محوریت **۱۰ روز تست رایگان بدون مبلغ عددی ثابت** و هدایت تمدید به ربات‌های بله.
