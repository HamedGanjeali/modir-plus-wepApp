# اسکیل تخصصی UI/UX مدیر پلاس (`my-ui-ux-skill`)

این نسخه از اسکیل UI/UX اختصاصاً برای وب‌سایت معرفی محصولات **مدیر پلاس** بازسازی و ارتقا یافته است:
- حذف کامل بخش‌های قدیمی اندروید (Java/XML) برای سبک‌سازی کانتکست ایجنت.
- هم‌راستاسازی ۱۰۰٪ با پشته **Astro + React Islands + Tailwind CSS v4 + TypeScript**.
- اضافه شدن دو دفترچه تخصصی جدید:
  - `08-rtl-persian-typography.md` برای مهندسی دقیق راست‌به‌چپ فارسی و `Vazirmatn`.
  - `09-product-showcase-conversion.md` برای طراحی تبدیل‌محور بر پایه سناریوی مدیران و معاونین مدارس ایران.
- پاک‌سازی کامل از ایموجی مطابق سیاست Zero-Emoji.
