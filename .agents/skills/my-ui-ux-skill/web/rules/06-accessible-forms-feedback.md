# Rule 06: Accessible Interactive Controls & Feedback

هر کنترل تعاملی (لایت‌باکس گالری، آکاردئون FAQ، تب سناریوها، دکمه کپی لینک صفحه) باید با کیبورد و صفحه‌خوان به‌طور کامل کار کند.

---

## ۱. الزامات لایت‌باکس و دیالوگ (`ProductLightboxGallery`)

1. **Focus Trapping:** هنگام باز بودن لایت‌باکس، زدن `Tab` و `Shift+Tab` فقط بین دکمه‌های داخل لایت‌باکس (بستن، تصویر قبلی، تصویر بعدی) بچرخد.
2. **کلیدهای کنترلی:**
   - `Escape`: بستن فوری لایت‌باکس.
   - `ArrowLeft` / `ArrowRight`: جابه‌جایی هماهنگ با چیدمان RTL.
3. **بازگردانی فوکوس (Focus Restoration):** پس از بستن لایت‌باکس، فوکوس دقیقاً به دکمه یا کارتی برگردد که آن را باز کرده است.
4. **متن جایگزین و شمارنده:** نمایش شماره اسلاید فعلی (`۱ از ۶` با `tabular-nums`) و کپشن واضح.

---

## ۲. آکاردئون سوالات متداول (`FaqAccordion`)

- هر پرسش با یک `<button>` استاندارد دارای `aria-expanded` و `aria-controls` پیاده شود (یا از `<details>` / `<summary>` بومی با انیمیشن تمیز استفاده شود).
- از `div` کلیک‌پذیر برای عنوان آکاردئون استفاده نشود.

---

## ۳. بازخورد فوری بدون پرش عرض (مثلاً دکمه کپی لینک)

هنگام کلیک روی دکمه «کپی لینک برای سیستم مدرسه»، متن دکمه به مدت ۲ ثانیه به «لینک کپی شد» تغییر می‌کند؛ عرض دکمه باید ثابت بماند (`min-w`) یا با لایه‌بندی غیرمخرب تغییر کند تا عناصر کناری تکان نخورند.
