# Rule 08: RTL Precision & Persian Typography (استاندارد راست‌به‌چپ و تایپوگرافی فارسی)

وب‌سایت مدیر پلاس منحصراً برای کاربران فارسی‌زبان طراحی می‌شود. طراحی با تفکر چپ‌به‌راست و برعکس کردن آن با یک کلاس، باعث اشکال در آیکون‌ها، سایه‌ها و حاشیه‌ها می‌شود.

---

## ۱. الزام ویژگی‌های منطقی CSS (Logical Properties)

در Tailwind CSS و CSS اختصاصی، استفاده از جهت‌های فیزیکی چپ/راست ممنوع است؛ همیشه از معادل منطقی استفاده کنید:

| ممنوع (فیزیکی) | الزامی (منطقی RTL-Safe) | کاربرد |
| :--- | :--- | :--- |
| `ml-*` / `mr-*` | `ms-*` / `me-*` | مارجین ابتدا و انتها |
| `pl-*` / `pr-*` | `ps-*` / `pe-*` | پدینگ ابتدا و انتها |
| `left-*` / `right-*` | `start-*` / `end-*` | موقعیت‌یابی `absolute` / `fixed` |
| `text-left` / `text-right` | `text-start` / `text-end` | تراز متن (جز در کدها و URLها) |
| `border-l` / `border-r` | `border-s` / `border-e` | حاشیه کناری کارت‌ها یا نقل‌قول |
| `rounded-l-*` / `rounded-r-*` | `rounded-s-*` / `rounded-e-*` | گردی گوشه‌های تب یا دکمه چسبان |

---

## ۲. نمایش صحیح شناسه‌های انگلیسی و URLها داخل متن فارسی (BiDi Safety)

عباراتی مانند `@Karnameh_plus_bot`، `sida.medu.ir`، `#آموزش_دفتر_آمار` یا نسخه `v2.5.0` داخل متن فارسی باید با `dir="ltr" class="inline-block"` ایزوله شوند تا علامت `@` یا `/` یا نقطه جابه‌جا نشود:

```tsx
<span dir="ltr" className="inline-block font-mono text-xs tabular-nums">
  @Karnameh_plus_bot
</span>
```

---

## ۳. تایپوگرافی `Vazirmatn` و اعداد فارسی

1. فونت پیش‌فرض کل بدنه `Vazirmatn` با `font-display: swap` است.
2. ارتفاع خط در تیترهای فارسی به دلیل حروف کشیده و نقطه‌دار نباید زیادی فشرده شود:
   - تیترهای بزرگ (`h1`, `h2`): `leading-[1.25]` تا `leading-[1.35]` و `text-wrap: balance`
   - متن بدنه و توضیحات (`p`): `leading-[1.75]` تا `leading-[1.85]` با حداکثر عرض `max-w-prose` (`~65ch`) برای خوانایی راحت روی دسکتاپ.
3. تمام اعداد متنی (تعداد زنگ‌ها، نسخه، شمارنده گام‌ها، مدت ویدیو، تاریخ) با ارقام فارسی (`۰-۹`) و ویژگی CSS `font-variant-numeric: tabular-nums` (`tabular-nums`) رندر شوند.

---

## ۴. جهت‌دهی آیکون‌ها در RTL

- **آیکون‌های جهت‌دار** (فلش ادامه، برگشت، Chevron صفحه قبل/بعد در گالری): در RTL باید به سمت **چپ** به معنی «ادامه / ورود به مرحله بعد» اشاره کنند (یا از کلاس `rtl:rotate-180` روی آیکون استاندارد چپ‌به‌راست استفاده شود).
- **آیکون‌های متقارن یا غیرجهت‌دار** (ذخیره، تیک تایید، چاپ، قفل، جستجو، خورشید/ماه): هرگز نباید معکوس (`rotate-180`) شوند.
- **کلیدهای جهت‌دار در لایت‌باکس RTL:** فشردن `ArrowLeft` باید تصویر بعدی (جلوتر در ترتیب راست‌به‌چپ) و `ArrowRight` تصویر قبلی را نشان دهد.
