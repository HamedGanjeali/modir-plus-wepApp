# Rule 04: Tailwind CSS v4 & Semantic Design Tokens

در **مدیر پلاس** از **Tailwind CSS v4** همراه با معماری توکن سه‌لایه در `src/styles/global.css` استفاده می‌شود تا سوییچ تم روشن و تیره آنی و بدون تکرار کد رنگ باشد.

---

## ۱. ساختار سه‌لایه توکن‌ها

1. **لایه پایه (`:root` و `.dark`):** تعریف مقادیر معنایی رنگ‌ها برای تم روشن اداری (`#f8fafc`) و تم تیره سرمه‌ای/OLED (`#0a0f1d`).
2. **لایه `@theme inline` در Tailwind v4:** نگاشت متغیرهای CSS به کلاس‌های Tailwind (`bg-background`، `bg-card`، `text-foreground`، `text-primary`، `border-border`).
3. **لایه کامپوننت:** تمام صفحات Astro و کامپوننت‌های React فقط از نام‌های معنایی استفاده می‌کنند و هرگز رنگ هگز خام داخل JSX/HTML نمی‌نویسند.

---

## ۲. نقشه رنگی مصوب مدیر پلاس (Porcelain Light / Obsidian Cobalt-Navy)

## ۳. جلوگیری از چشمک‌زدن تم هنگام بارگذاری (Zero-FOUC)

اسکریپت تشخیص تم (`localStorage` + `prefers-color-scheme`) به‌صورت یک اسکریپت کوچک inline قبل از رندر بدنه در `<head>` داخل `BaseLayout.astro` اجرا می‌شود تا صفحه در تم تیره هرگز لحظه‌ای سفید نشود.
