# فاز ۲: صفحه اصلی (`/`), ویترین محصولات و ماتریس انتخاب

**هدف:** تبدیل اسکلت صفحه اصلی به یک صفحه معرفی تراز اول، مدرن و تبدیلی برای برند **مدیر پلاس (`modir-plus.ir`)** بر پایه سناریوهای واقعی مدیران و معاونین.

---

## فهرست تسک‌ها

- **`[TASK-LND-201]` [STATUS: DONE]** پیاده‌سازی بخش **Hero صفحه اصلی**:
  - تیتر شفاف ارزش پیشنهادی برای مدیران و معاونین مدارس (`text-wrap: balance`)
  - نشانگر سیاست یکپارچه **۱۰ روز تست رایگان بدون کارت بانکی**
  - دو دکمه اقدام: مشاهده محصولات و آشنایی با هاب آموزشی ایتا
  - کارت/ویزوال خلاصه وضعیت ابزارهای اکوسیستم مدیر پلاس با `CLS = 0`.
- **`[TASK-LND-202]` [STATUS: DONE]** پیاده‌سازی **گرید بنتوی ویترین محصولات (`ProductShowcaseGrid`)**:
  - دو کارت پرجزئیات و جذاب برای **سیدا پلاس (v2.5.0)** و **کارنامه پلاس (v1.0.0)** همراه با `transition:name` برای View Transitions نرم به صفحه اختصاصی محصول.
  - پیش‌نمایش مینیاتوری واقعی رابط کاربری هر محصول داخل کارت، مخاطبان هدف، ۳ دستاورد کلیدی، و دکمه «بررسی کامل، تصاویر و دانلود».
  - پیش‌بینی یک کارت شفاف «محصولات در دست توسعه (به‌زودی)» برای توسعه آتی سبد مدیر پلاس بدون به‌هم زدن توازن گرید.
- **`[TASK-LND-203]` [STATUS: PENDING]** پیاده‌سازی **ماتریس تصمیم‌گیری ۳۰ ثانیه‌ای (`کدام ابزار مشکل امروز شما را حل می‌کند؟`)**:
  - دسته‌بندی بر اساس نیاز واقعی دفتر مدرسه:
    - کارهای صفحه سیدا، دفتر آمار، برنامه هفتگی و مدیریت گروه‌های شاد -> سیدا پلاس
    - جمع‌آوری نمره از دبیران، انضباط ۶ زنگی، پورتال اولیا و چاپ کارنامه -> کارنامه پلاس
    - مدیریت کامل طول سال تحصیلی -> استفاده ترکیبی از هر دو
- **`[TASK-LND-204]` [STATUS: PENDING]** پیاده‌سازی بخش **سیاست شفافیت، حریم خصوصی مدارس و دعوت به هاب ایتا**:
  - نمایش اصول اعتماد (ذخیره‌سازی امن داده‌های دانش‌آموزان، سازگاری چندمرورگره Chrome/Edge/Firefox، آموزش‌های لقمه‌ای ۳۰ تا ۶۰ ثانیه‌ای در ایتا و پشتیبانی بله).
  - خلاصه آکاردئونی سوالات کلیدی صفحه اصلی (`FaqAccordion.tsx`).
