# ADR-001: پشته فنی Astro + React Islands و مسیرهای اختصاصی محصولات

## Status

PROPOSED

## Date

2026-11-26

## Context

وب‌سایت مدیر پلاس باید هم به عنوان ویترین فروش و اعتمادسازی برای مدیران و معاونین مدارس با اینترنت موبایل/اداری فوق‌العاده سریع لود شود و سئوی قوی داشته باشد، و هم بخش‌های تعاملی جذابی مانند گالری لایت‌باکس، شبیه‌ساز مراحل کاری محصولات و کادر نصب هوشمند مرورگر را ارائه دهد. علاوه بر این، لینک هر محصول باید مستقیماً در پیام‌رسان‌های بله و ایتا قابل اشتراک‌گذاری باشد.

## Options Considered

### Option A: Astro + React Islands + Tailwind CSS v4 (Static Output روی Cloudflare Pages) + مسیر اختصاصی محصولات
- Pros: بارگذاری نزدیک به آنی (Zero-JS پیش‌فرض)، سئوی کامل HTML استاتیک، View Transitions بومی نرم بین کارت و صفحه محصول، Deep-linking مستقیم برای اشتراک‌گذاری در ایتا و بله، استفاده تمیز از کامپوننت‌های تعاملی React فقط در نقاط لازم.
- Cons: تفکیک لایه `.astro` و `.tsx` نیازمند رعایت مرزبندی Islandها در راهنمای تیم است.

### Option B: تک‌صفحه‌ای SPA (Vite + React) همراه با Modal برای معرفی محصولات
- Pros: کل کد داخل React یکدست است.
- Cons: ضعف در سئوی اولیه و متای اشتراک‌گذاری، محدودیت فضای نمایش گالری و سناریوها در موبایل داخل مودال، سربار اولیه JS بیشتر.

## Decision

انتخاب **Option A (Astro + React Islands + Tailwind CSS v4 + TypeScript)** همراه با صفحات اختصاصی لینک‌پذیر (`/products/sida-plus` و `/products/karnameh-plus`) و انتقال نرم View Transitions.

## Consequences

- کل داده‌های محصول در `src/data/products.ts` متمرکز می‌شود تا هر دو صفحه و ماتریس مقایسه از یک منبع خوانده شوند.
- دیپلوی روی Cloudflare Pages بدون نیاز به سرور بک‌اند مجزا و با هزینه صفر عملیاتی انجام می‌شود.
- این تصمیم در مصاحبه کشف الزامات با مالک محصول هماهنگ شده و در انتظار تایید رسمی وضعیت به `ACCEPTED` در اولین بازبینی پروژه است.
